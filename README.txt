САЙТ КУЗОВНОГО РЕМОНТА — КАК ОТКРЫТЬ И ИЗМЕНИТЬ

1. Распакуйте ZIP-архив в отдельную папку.
2. Откройте файл index.html двойным щелчком — сайт откроется в браузере.
3. Чтобы изменить текст, откройте index.html в редакторе (например, Notepad / Блокнот или Visual Studio Code).
4. После изменения сохраните файл и обновите страницу браузера.
5. Чтобы поменять цвета и оформление, откройте style.css. Цвета сайта находятся в самом начале, в разделе :root.

ВАЖНО:
- Не удаляйте кавычки и угловые скобки вокруг HTML-тегов.
- Перед изменениями сделайте копию исходных файлов.
- Файлы index.html и style.css должны оставаться в одной папке.
- Пока сайт открыт только на вашем компьютере. Чтобы другие люди увидели его в интернете, нужно разместить файлы на хостинге и при желании подключить домен.
- Ссылка на карте открывает поиск адреса в Google Maps; проверьте точность метки перед публикацией.
- В тексте используется формулировка «Полировка кузова» вместо опечатки «палеровка», а «защитные керамические покрытия» — вместо неясной формулировки. При желании их можно заменить в index.html.
